# Video Assets Folder

## Loading Screen Video

**Please place your loading screen video file here.**

### Required Video Specifications:
- **Filename**: `loading-video.mp4` (exactly this name)
- **Duration**: 2.22 seconds (2220 milliseconds)
- **Resolution**: 1920x1080 (Full HD) recommended
- **Format**: MP4 (H.264 codec)
- **File Size**: Keep under 5MB for optimal web performance
- **Content**: Red and blue karate gloves touching

### Video Optimization Tips:
1. Use H.264 codec for best browser compatibility
2. Compress for web delivery (use tools like HandBrake or Adobe Media Encoder)
3. Ensure video is exactly 2 seconds long
4. Test on mobile devices to ensure smooth playback

### File Location:
Place your video file at:
```
karate-dojo/assets/videos/loading-video.mp4
```

### Fallback Behavior:
If the video file is not found or fails to load, the loading screen will display:
- Black background
- "Right Strike" text centered
- Same 2-second animation timing

The website will function normally without the video, but adding the video creates a premium brand experience.
